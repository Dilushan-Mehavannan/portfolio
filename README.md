# Mehavannan Dilushan — Professional Industry Portfolio

A high-performance, dark-themed, interactive portfolio website for **Mehavannan Dilushan** — Full-Stack Developer & Physics/Electronics Specialist.

![Portfolio Preview](profile-photo.png)

## 🌟 Highlights & Key Features

- **Dynamic GitHub API Integration**: Real-time fetching of public repositories, star counts, fork counts, primary languages, and live profile metrics from `@Dilushan-Mehavannan`.
- **Live Search & Category Filtering**: Search repositories by name, language, or topic with instant client-side filtering.
- **GitHub Contribution Activity Feed**: Displays real-time GitHub activity (pushes, stars, forks, repo creation) with relative time-ago calculations and refresh capabilities.
- **Modern Glassmorphic Dark UI**: Custom color system built with CSS design tokens, mouse-tracking spotlight glow cards, backdrop blurs, and animated mesh glows.
- **Dual-Degree & Multi-disciplinary Spotlight**: Tailored for both **Full-Stack Software Engineering** and **Applied Physics & Electronics / Embedded IoT Systems**.
- **Interactive Micro-Interactions**:
  - One-click copy email to clipboard with animated toast notification.
  - Interactive spotlight gradient tracking on card hovers.
  - Custom fluid cursor follower.
  - Fully responsive mobile drawer navigation menu.
- **Formspree Contact Integration**: Zero-backend static contact form submission with instant feedback.
- **100% Static & Production Ready**: Blazing fast load times with 0 dependencies or build step required.

## 🚀 How to Run Locally

### Option 1: Direct File
Simply double-click `index.html` or open it in any browser.

### Option 2: Local Server (Node / Python)
```bash
# Using npx serve
npx serve .

# Or using Python
python -m http.server 8000
```
Open `http://localhost:8000` or `http://localhost:3000` in your browser.

## 🌐 Deploying to Production

This project can be deployed instantly to any static hosting provider:
- **Vercel**: Import repository -> Framework Preset: *Other* / *Static Site*.
- **GitHub Pages**: Push to `main` branch -> Enable GitHub Pages in repository settings.
- **Netlify**: Drag & drop project folder or link GitHub repo.
