# Mehavannan Dilushan — Portfolio

A fully responsive, dark & minimal portfolio website.

## Files
- `index.html` — Main HTML file
- `style.css` — All styles
- `script.js` — GitHub API integration + interactivity
- `photo.jpg` — Profile photo

## Features
- Live GitHub profile & repository fetching via GitHub API
- Project filtering by programming language
- GitHub activity feed
- Smooth scroll reveal animations
- Custom cursor
- Responsive for mobile, tablet, desktop

## GitHub Username
The portfolio is configured for: `DilushanMehavannan`
To change it, update `GITHUB_USER` in `script.js` line 1.

## How to Use
Simply open `index.html` in a browser — no build step needed.
For best results, host on GitHub Pages, Netlify, or Vercel.
